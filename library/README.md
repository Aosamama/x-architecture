# library/ — files hosted for direct download

Files here are offered from the site's Library page (button "تنزيل"). Host a file here ONLY when its licence allows redistribution:

- CC0 / public domain (e.g. Poly Haven, ambientCG)
- SIL OFL fonts (include each font's OFL.txt in the zip)
- the studio's own work

Not allowed here: Pixabay, Unsplash, BlenderKit, Adobe, Mr Cutout, Skalgubbar, Non Scandinavia (non-commercial) or anything whose terms do not say we may redistribute it. Those stay as links to the original source.

Every hosted zip must contain a README with the source URL and the licence. Keep single files well under 100 MB (GitHub's push limit) and the whole folder small (GitHub Pages is meant for sites under ~1 GB).

To add a file: put it in a subfolder here, then add the path and a size label as the last two fields of the item in `SFB` inside index.html (fields 9 and 10, after the optional notes).

## fonts/
- `xarch-arabic-fonts.zip`: Tajawal, Cairo, Almarai, IBM Plex Sans Arabic, Noto Kufi Arabic
- `xarch-latin-fonts.zip`: Jost, Montserrat, Josefin Sans, Raleway, Inter

Source: github.com/google/fonts (SIL OFL 1.1). Variable fonts are renamed `*-Variable.ttf`; font contents are unchanged.
